# Thymosin Alpha-1

## Foods to Eat

- **Citrus Fruits** (oranges, lemons, grapefruit) — high in vitamin C, which supports neutrophil and T-cell function
- **Garlic** — contains allicin, which enhances NK cell and macrophage activity; supports the same immune pathways Thymosin Alpha-1 modulates
- **Ginger** — anti-inflammatory and immune-stimulating; reduces chronic inflammation that impairs T-cell function
- **Medicinal Mushrooms** (shiitake, maitake, reishi, lion's mane) — contain beta-glucans that activate macrophages and enhance adaptive immunity
- **Leafy Greens** (spinach, kale, Swiss chard) — rich in folate, iron, and vitamins A/C/K needed for immune cell production
- **Fermented Foods** (sauerkraut, kimchi, kefir, yogurt, miso) — support gut microbiome diversity, which directly modulates systemic immune function (70% of immune tissue is in the gut)
- **Wild-Caught Fatty Fish** (salmon, sardines, mackerel) — omega-3 fatty acids reduce chronic inflammation and support immune cell membrane integrity
- **Bone Broth** — provides glutamine for gut barrier integrity and minerals for immune function
- **Zinc-Rich Foods** (oysters, pumpkin seeds, grass-fed beef) — zinc is essential for T-cell development and thymic function
- **Turmeric** — curcumin modulates cytokine production and supports balanced immune responses
- **Berries** (blueberries, elderberries, blackberries) — rich in anthocyanins and polyphenols that support immune defense

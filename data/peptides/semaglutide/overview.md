# Semaglutide

## Overview

Semaglutide is a GLP-1 (glucagon-like peptide-1) receptor agonist developed by Novo Nordisk. FDA-approved as Ozempic (diabetes), Wegovy (weight management), and Rybelsus (oral diabetes). The drug that ignited the global GLP-1 weight loss revolution. Originally developed for type 2 diabetes, the weight loss effects were so dramatic that it spawned the weight management indication. Available as weekly injection or daily oral tablet.

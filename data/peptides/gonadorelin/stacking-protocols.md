# Gonadorelin

## Stacking Protocols

- **HPG Axis Restart Stack**: Gonadorelin (100-200mcg pulsatile) + Kisspeptin (1-10 mcg/kg) — kisspeptin stimulates upstream GnRH neurons while gonadorelin acts directly at the pituitary; complementary points on the same axis, use under supervision.
- **TRT Testicular Maintenance Stack**: Gonadorelin (100-200mcg, several times weekly) + Zinc (15-30mg) + Vitamin D3 (2000-5000 IU) — maintains testicular function on TRT with nutrient cofactors for steroidogenesis.
- **Fertility Support Stack**: Gonadorelin (pulsatile per protocol) + Omega-3 (2-3g) — supports spermatogenesis with anti-inflammatory Leydig cell support; medical supervision required.
- **Recovery & Vitality Stack**: Gonadorelin (100-200mcg pulsatile) + Ashwagandha (300-600mg) + Magnesium (300-400mg) — axis stimulation plus cortisol and free-testosterone support.
- **IMPORTANT**: Gonadorelin's hormonal stacks should be run with a clinician and regular blood work; pulsatile timing is non-negotiable.

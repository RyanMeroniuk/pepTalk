# Growth Hormone (Somatropin)

## Stacking Protocols

- **Medical context note**: Somatropin is a prescription hormone; the combinations below reflect how it is discussed in the broader community, but it should only be used under physician supervision
- **GH + Secretagogue (generally redundant)**: Combining somatropin with GH secretagogues like CJC-1295 or Ipamorelin is largely redundant — exogenous GH already supplies the hormone and suppresses the need to stimulate endogenous release
- **Recomp context**: Somatropin + Tesamorelin (2mg/day) — both reduce visceral fat, but stacking two GH-axis agents amplifies insulin-resistance and IGF-1 risk; rarely appropriate outside specific medical scenarios
- **Recovery Stack**: Somatropin + BPC-157 (250mcg 2x/day) + TB-500 (2mg 2x/week) — pairs systemic GH/IGF-1 with direct tissue-healing peptides
- **Metabolic Support Stack**: Somatropin + MOTS-c (5mg 2x/week) — MOTS-c supports insulin sensitivity, which may help offset GH's diabetogenic effect
- **Lean Mass context**: Somatropin + IGF-1 LR3 (40mcg/day) — stacks GH-driven IGF-1 with direct IGF-1 signaling, sharply increasing proliferative/hypoglycemic risk; high-risk and not advisable casually
- **Note**: Stacking multiple GH/IGF-axis agents compounds insulin resistance and IGF-1 elevation; these are reference combinations, not endorsements

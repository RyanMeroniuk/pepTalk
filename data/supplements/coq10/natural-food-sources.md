# CoQ10 (Coenzyme Q10)
## Natural Food Sources

- **Organ meats (highest concentration):**
  - **Beef heart** — 11.3mg per 100g (the richest known dietary source)
  - **Beef liver** — 3.9mg per 100g
  - **Pork heart** — 11.8mg per 100g
  - **Chicken heart** — 9.2mg per 100g
  - **Pork liver** — 2.7mg per 100g
- **Meat and poultry:**
  - **Beef (muscle meat)** — 3.1mg per 100g
  - **Pork (muscle meat)** — 2.4-4.1mg per 100g
  - **Chicken thigh** — 1.4mg per 100g
  - **Chicken breast** — 0.7mg per 100g
- **Fish:**
  - **Sardines** — 6.4mg per 100g
  - **Mackerel** — 4.3mg per 100g
  - **Herring** — 2.7mg per 100g
  - **Rainbow trout** — 1.1mg per 100g
  - **Tuna** — 1.6mg per 100g
- **Nuts and seeds:**
  - **Peanuts** — 2.6mg per 100g
  - **Pistachios** — 2.0mg per 100g
  - **Sesame seeds** — 1.7mg per 100g
  - **Walnuts** — 1.3mg per 100g
- **Oils:**
  - **Soybean oil** — 9.2mg per 100g
  - **Canola oil** — 6.4mg per 100g
  - **Olive oil** — 0.4mg per 100g
- **Vegetables (modest amounts):**
  - **Spinach** — 1.0mg per 100g
  - **Broccoli** — 0.7mg per 100g
  - **Cauliflower** — 0.4mg per 100g
- **Other:**
  - **Soybeans** — 1.2mg per 100g
  - **Avocado** — 0.95mg per 100g
  - **Oranges** — 0.2mg per 100g

**Note:** The typical Western diet provides only 3-6mg of CoQ10 per day. Therapeutic doses start at 100mg/day — dietary sources alone cannot replace supplementation when CoQ10 levels are depleted.

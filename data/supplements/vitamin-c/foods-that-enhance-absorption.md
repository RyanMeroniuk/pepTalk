# Vitamin C
## Foods That Enhance Absorption

### Bioflavonoid-Rich Foods (enhance vitamin C uptake and extend its activity)
- **Citrus fruits (oranges, lemons, grapefruit):** Contain hesperidin and naringenin, bioflavonoids that slow vitamin C degradation and improve cellular uptake. This is why whole fruit vitamin C is better retained than isolated ascorbic acid.
- **Berries (blueberries, blackberries, elderberries):** Rich in anthocyanins and quercetin, which synergize with vitamin C for antioxidant protection and recycling.
- **Grapes (especially red/purple, including seeds):** Contain proanthocyanidins (OPCs) that work synergistically with vitamin C to strengthen collagen and protect blood vessels.
- **Buckwheat:** Rich in rutin, a bioflavonoid that enhances vitamin C absorption and protects capillary integrity.
- **Green tea:** Contains catechins (EGCG) that synergize with vitamin C for antioxidant and anti-inflammatory effects.
- **Onions (especially red):** Rich in quercetin, which enhances vitamin C's anti-inflammatory and antihistamine effects.
- **Dark chocolate (70%+):** Contains flavanols that complement vitamin C's cardiovascular benefits.

### Iron-Rich Foods (vitamin C enhances iron absorption from these foods)
- **Spinach, kale, Swiss chard:** Non-heme iron is poorly absorbed alone; vitamin C increases absorption 2-6x
- **Lentils, chickpeas, black beans:** Pair with vitamin C-rich foods to dramatically improve iron uptake
- **Tofu and tempeh:** Plant-based iron sources that benefit from vitamin C co-consumption
- **Fortified cereals:** Non-heme iron in fortified foods is enhanced by vitamin C

### Vitamin E-Rich Foods (vitamin C regenerates vitamin E)
- **Almonds:** Vitamin E from almonds + vitamin C creates an antioxidant recycling pair
- **Sunflower seeds:** High in vitamin E, synergistic with vitamin C
- **Avocado:** Contains both vitamin E and healthy fats
- **Olive oil:** Vitamin E content complemented by vitamin C

### Glutathione-Rich/Supporting Foods (vitamin C and glutathione recycle each other)
- **Asparagus:** One of the highest food sources of glutathione
- **Avocado:** Rich in glutathione precursors
- **Cruciferous vegetables (broccoli, cauliflower, Brussels sprouts):** Contain sulforaphane which upregulates glutathione synthesis; also contain their own vitamin C
- **Whey protein:** Provides cysteine for glutathione synthesis, synergizing with vitamin C's antioxidant network

### General Principle
- **Eat vitamin C-rich foods with every meal** to maximize nutrient synergies, especially iron absorption from plant foods.
- **Whole food sources of vitamin C naturally contain bioflavonoids,** making them inherently more bioavailable than isolated ascorbic acid supplements.
